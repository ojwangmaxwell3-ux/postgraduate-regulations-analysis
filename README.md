# Postgraduate Regulations Analysis

## Project Overview
This project examines postgraduate regulations using data cleaning,
exploratory data analysis, statistical analysis and evidence-based interpretation.

## Project Contents
- postgraduate_regulations_corrected_cleaned.csv: Corrected and cleaned dataset.
- postgraduate.ipynb: Jupyter Notebook containing the analysis.
- results/: Statistical outputs, reports and analytical findings.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Statistical analysis

## Objectives
- Examine postgraduate regulatory compliance.
- Identify critical regulatory areas.
- Analyse missing data and qualitative feedback.
- Generate evidence-based recommendations.
